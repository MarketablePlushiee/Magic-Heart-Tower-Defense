# 💖 Magic Heart - Survival Defense (Unity URP)

An action-arcade survival defense game built with **Unity (Universal Render Pipeline)** targeting mobile and touch platforms. Features dynamic wave generation algorithms, custom visual shaders, and audio architecture.

---

## 🛠️ Tech Stack & Features

* **Game Engine:** Unity 3D (URP)
* **Programming Language:** C#
* **Graphics & VFX:** Custom Shader Graph (Ice slowdown, Magma DOT, hit feedback)
* **Target Platforms:** WebGL, Mobile / Touch

---

## 🎮 Key Systems & Architecture

* **Wave Spawning System:** Dynamic algorithms with progressive difficulty scaling over time.
* **Game Feel & VFX:** Custom Shader Graphs combined with procedural squash and stretch mechanics for hit feedback.
* **Audio Architecture:** Multi-channel AudioMixer with dynamic pause controls and state management.
* **Input System:** Hybrid touch and mouse Raycast tracking optimized for mobile playability.

# 💖 Magic Heart - Defensa y Supervivencia (Unity URP)

Un juego de defensa y supervivencia arcade de acción construido con **Unity (Universal Render Pipeline)** enfocado para plataformas móviles y táctiles. Cuenta con algoritmos de generación dinámica de oleadas, shaders visuales personalizados y arquitectura de audio.

---

## 🛠️ Tecnologías y Características

* **Motor de Juego:** Unity 3D (URP)
* **Lenguaje de Programación:** C#
* **Gráficos y VFX:** Shader Graph personalizado (ralentización por hielo, daño por tiempo de magma, retroalimentación de impacto)
* **Plataformas Objetivo:** WebGL, Móvil / Táctil

---

## 🎮 Sistemas Clave y Arquitectura

* **Sistema de Generación de Oleadas:** Algoritmos dinámicos con escalado de dificultad progresivo a lo largo del tiempo.
* **Game Feel y VFX:** Gráficos de Shaders personalizados combinados con mecánicas procedurales de estiramiento y compresión (*squash and stretch*) para retroalimentación de impacto.
* **Arquitectura de Audio:** AudioMixer multicanal con controles dinámicos de pausa y gestión de estados.
* **Sistema de Entrada:** Seguimiento híbrido táctil y por mouse mediante Raycast optimizado para la jugabilidad en dispositivos móviles.
