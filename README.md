# 💖 Magic Heart - Survival Defense (Unity URP)

An action-arcade survival defense game built with **Unity (Universal Render Pipeline)** targeting mobile and touch platforms. Features dynamic wave generation algorithms, custom visual shaders, and audio architecture.

---

## 🛠️ Tech Stack & Features

* **Game Engine:** Unity 3D (URP)
* **Programming Language:** C#
* **Graphics & VFX:** Custom Shader Graph (Ice slowdown, Magma DOT, hit feedback)
* **Target Platforms:** WebGL, Mobile / Touch

---

## 🎮 Key Systems & Architecture

* **Wave Spawning System:** Dynamic algorithms with progressive difficulty scaling over time.
* **Game Feel & VFX:** Custom Shader Graphs combined with procedural squash and stretch mechanics for hit feedback.
* **Audio Architecture:** Multi-channel AudioMixer with dynamic pause controls and state management.
* **Input System:** Hybrid touch and mouse Raycast tracking optimized for mobile playability.
